# Proposed first research preview

**Draft release notes; no public release has been published.**

Ge’ez Lab shares manuscript transcription research from
[EthiopianCanon.com](https://ethiopiancanon.com): 68 consecutive provisional
Ge’ez side readings, comparison records, a working scribal key, and portable
Python tools. The package documents its source manuscript, methods, failures,
retractions, and open questions so others can inspect and extend the work.

Code is MIT licensed. Original research is CC BY 4.0 with EthiopianCanon.com
attribution. Manuscript images are obtained separately from University Library
Tübingen; third-party source terms remain their own.

The readings await complete expert review. This release must be described as a
research preview, with no claim of a completed Qalementos translation or measured
character accuracy on the manuscript.

Before publishing: run the documented checks, inspect the release diff, confirm
library access, choose the version and date, and identify the exact commit.
After publishing: replace this draft notice with the actual release information
and update CHANGELOG.md and CITATION.cff. A later EthiopianCanon.com blog can
link the release and invite evidence-backed corrections and expert collaboration.
