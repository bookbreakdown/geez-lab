# Historical calibration readings

Ge’ez Lab / [EthiopianCanon.com](https://ethiopiancanon.com).

The directory name is retained from the experiment. **These 12 files are model
readings and calibration investigations, not verified ground truth.** Some
contradict each other or contain findings later retracted. See
[history](../docs/HISTORY.md) and [methodology](../docs/METHODOLOGY.md).

An English witness based on d’Abbadie 78 cannot establish exact character accuracy
for Ma IX 1. Images and modern reference answers are excluded from this package.
For image locations, use the source mapping formula documented in
[SOURCES.md](../docs/SOURCES.md), including for calibration sides before 152r.
