# Ge’ez Lab

This is provisional research from https://ethiopiancanon.com. Read README.md,
docs/STATUS.md, and CONTRIBUTING.md first.

- Keep archived readings unchanged. Add proposed corrections under reviews/.
- Never present confidence, agreement, a question-mark count, or a translation
  of another witness as exact manuscript transcription accuracy.
- Preserve uncertainty and retractions. Keep original and proposed readings visible.
- Use checkout-relative paths and Python 3.10+ standard library for core tools.
- Do not commit image downloads, private correspondence, credentials, or modern
  reference translations. Preserve source provenance and licence boundaries.
- The intended commercial English translation must use cleared source material.
  The 2008 printed Qalementos edition and digitisation derived from it are
  excluded as translation sources unless explicit permission for that use is
  obtained. Do not infer clearance from the ancient underlying text or a
  hosting site's general open licence. See docs/SOURCES.md.
- Credit Ge’ez Lab / https://ethiopiancanon.com in new public-facing materials.
- Run scripts/validate_release.py and unittest discovery before completing edits.
- Public visibility changes, release tags, and publication require an explicit
  release instruction. Preparing this repository does not publish a release.
