## UNCERTAIN
- Line 2 and line 7, ሠጋት: the sibilant is written with the looped ሠ form, not ሥ; standard ሥጋት "bodies/flesh". Kept as written.
- Line 5, ትሪኃው (with ይ carried from line 4): second letter read as ሪ; expected form ይትረኃው "are opened". The third letter could be ኃ or ጎ; ኃ chosen from the shape of the base.
- Line 7, first letter written as ?: a ት-like glyph with an extra hook that does not match plain ት; context would want ይ (ወይነብሩ "and they dwell") or ት (ወትነብር), but the pixels support neither cleanly.
- Line 8, ተወር?: the last letter is an ኦ/ድ-shaped glyph I cannot resolve; expected ትወርድ "descends". Also the first letter looks like ተ rather than ት.
- Line 8, በጠሊ: the ጠ is followed by ሊ where standard would be ጠለ "dew of"; kept as written.
- Line 10 and line 12: the double-colon punctuation ፡፡ carries red dots (ornamented section mark), transcribed as ፡፡.
- Line 19, እባ (continuing into line 20 ቀብከሙ): read as እባ but the sense requires ኢዐቀብከሙ "you did not keep"; the first letter may be ኢ and the second ዐ/ዓ rather than ባ. Flagged rather than corrected.
- Line 20, ትእዘዘ: written with ዘ twice; standard ትእዛዘ "the commandment of". Kept as written.
- Line 21, ወደወስዶዎሙ: second letter read as ደ (expected ይ) and fifth as ዶ (expected ዱ) for ወይወስዱዎሙ "and they take them". Kept as written.
- Line 22, ወሐቅየ: standard ሐቀየ; the second-order ቅ is what the page shows.
