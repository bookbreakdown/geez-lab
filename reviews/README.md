# Reviews and corrections

Ge’ez Lab / [EthiopianCanon.com](https://ethiopiancanon.com).

No expert reviews are represented as complete in the initial package.
Add a review as `MAIX1-153R-your-name.md`, preserving the imported draft.

Include: reviewer name or chosen credit; date; qualifications if volunteered;
source image URL and dimensions; line number; original reading; proposed reading;
evidence; alternatives; confidence; AI assistance; and any translations consulted.
State whether this is a proposal, independent review, or adjudication. Cite the
commit reviewed. Link related issues and leave disagreement visible.

Original review contributions use CC BY 4.0. Retain the Ge’ez Lab /
EthiopianCanon.com project attribution and add your own contributor credit.
